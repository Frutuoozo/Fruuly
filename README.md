# Fruuly

Player de música no navegador, feito com HTML, CSS e JavaScript puros (sem frameworks).
Toca arquivos MP3 do seu computador; nenhum arquivo é enviado a servidores.

## Como usar

Abra o `index.html` no navegador e clique em **Adicionar músicas** (ou arraste os MP3 para a janela).
Funciona no computador, tablet e celular.
